# 数据来源

## MARD 221

- 数据集：`HansBug/pindou-color-data/mard-221-alfonse-doudou/colors.json`
- 上游地址：https://github.com/HansBug/pindou-color-data
- 数据集生成日期：2026-05-19
- 色号数量：221
- 分组：A(26)、B(32)、C(29)、D(26)、E(24)、F(25)、G(21)、H(23)、M(15)
- 许可证：MIT License；完整文本位于 `app/src/main/assets/MARD_COLOR_DATA_LICENSE.txt`

该仓库说明两个公开 MARD 221 来源的色号集合一致，但 77 个 HEX/RGB 值不同。因此本项目只把 `code` 用作库存与 OCR 的标准身份，`hex` 只用于屏幕上的近似色块。
