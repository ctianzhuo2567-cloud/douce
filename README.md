# 豆册（工作名）

Android 本地图纸与拼豆库存管理 App。当前聚焦 MARD221 图纸整理、离线色号识别、独立网格编辑、高亮和镜像。

## 已搭建

- Kotlin + Jetpack Compose 单 Activity 项目
- 无渐变的低饱和粉紫“莓果纸艺”视觉主题
- 图纸库、搜索，以及状态 / 标签 / 收藏组合筛选
- 图纸名称、标签和备注编辑
- Android 系统文件选择器批量导入图片
- 导入图纸会复制到 App 私有目录，避免原相册文件移动后失效
- 完整 ZIP 备份与恢复，包含原图、整理信息、镜像状态和库存
- 大图采样加载、双指缩放和拖动查看
- 左右 / 上下预览镜像，原图不覆盖
- 色号说明区域框选，按图片比例保存位置
- MARD 221 全色号豆库、库存搜索与系列筛选
- 有库存、快用完、缺货、未录入四种库存状态
- 快速增减 100 颗、精确数量录入与本地调整记录
- 按色号批量录入，支持 +500 / +1000 / +1200 快捷数量
- MARD 221 整套入库，可选择追加库存或统一设为指定数量
- App 固定使用 MARD 221，不混入 291 扩展色号
- 常见 OCR 色号格式标准化和合法范围校验
- ML Kit 离线 OCR，图例支持原图、增强和反色多路识别
- 网格框选后自动测算行列数，低置信度结果必须人工确认
- 网格按行分段放大 OCR，改善密集小字的检出率
- 独立网格支持色号高亮、逐格修改、擦除和漏色补录

## 明确暂缓

- 豆仓位置与收纳盒管理
- 只有彩色方格、没有色号说明的图纸识别
- 颜色匹配
- 云同步与账号
- MARD 291 或其他品牌色卡

## 运行要求

- Android Studio Panda 3 或兼容 API 37 的更新版本
- JDK 17
- Android SDK 37
- Gradle 9.6（项目 wrapper 配置已指定；首次同步需要联网下载）

在 Android Studio 中打开项目根目录，等待 Gradle Sync 完成，然后运行 `app`。

APK 由 GitHub Actions 在云端编译、测试和签名；本地可用 ADB 将云端产物直接安装到安卓真机。

## 在电脑上预览

双击项目根目录的 `预览豆册界面.bat`。浏览器预览会直接读取 `拼豆测试图纸/` 中的图片，可体验图纸筛选、收藏、镜像、框选说明区域，以及 MARD 221 豆库快捷入库。

浏览器预览只用于确认界面与操作方向，不能替代安卓真机测试。安装 Android Studio 后，还可以使用 Compose Preview、安卓模拟器，或连接实体手机运行正式 App。

## 后续更新

版本升级与安装方式见 `docs/UPDATE_WORKFLOW.md`。关键原则是保持应用包名和签名证书不变，并在每个发布版本递增 `versionCode`；这样新 APK 可以覆盖安装且保留本地数据。

仓库使用 GitHub Actions 构建固定证书签名的正式 APK。推送版本提交并创建 `v*` 标签后，会自动生成 GitHub Release 和可直接下载的 APK；签名材料仅保存在本地忽略目录与 GitHub 加密 Secrets 中。

## 测试图纸

`拼豆测试图纸/` 中的 7 张图片保留为真实测试样本，不会被打包进 APK。后续用于测试大图加载、色号说明区域裁剪、OCR、镜像和水印干扰。

## MARD 221 数据

内置目录共 221 色，分组为 A(26)、B(32)、C(29)、D(26)、E(24)、F(25)、G(21)、H(23)、M(15)。色号与屏幕 HEX 数据来自 `HansBug/pindou-color-data` 的 MARD 221 核对版，按 MIT License 使用，授权文本保存在 App assets 中。

不同公开 MARD 221 数据源对部分 HEX 值存在差异，因此 App 只把色号视为库存身份；屏幕颜色仅用于快速查找，不能替代实体色卡。
